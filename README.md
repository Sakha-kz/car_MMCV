## 1. Системные требования и Ограничения
- **VRAM Ограничение:** $\le 4$ GB (целевые ускорители: NVIDIA P106-100, RTX 3050 Laptop, GTX 1650/1050Ti).
- **Разрешение входного видео:** Full HD (1920x1080), 30-60 FPS, 1 минута.
- **Целевая точность OCR:** $\ge 99\%$ Exact Match Sequence Accuracy на валидации.
- **Скорость инференса:** реальное время ($\le 12$ мс на номер при INT8 квантовании).

## 3. Архитектура Моделей и Алгоритмы

### 3.1. CRNN OCR (`anpr_system/models/cnn_crnn.py`)
Архитектура состоит из трех ключевых блоков:
1. **CNN Feature Extractor (6 сверточных слоев):**
   - $32 \times 128 \times 1 \to$ `Conv2D(64)` $\to$ `ReLU` $\to$ `MaxPool(2,2)`
   - `Conv2D(128)` $\to$ `ReLU` $\to$ `MaxPool(2,2)`
   - `Conv2D(256)` $\to$ `BatchNorm` $\to$ `ReLU`
   - `Conv2D(256)` $\to$ `ReLU` $\to$ `MaxPool((2,1))`
   - `Conv2D(512)` $\to$ `BatchNorm` $\to$ `ReLU`
   - `Conv2D(512)` $\to$ `ReLU` $\to$ `MaxPool((2,1))`
   - Выходной тензор признаков: $(B, 512, 2, 32) \to$ преобразуется в $(B, \text{seq\_len}=32, \text{features}=1024)$.
2. **Рекуррентный блок (Recurrent Stage):**
   - Двунаправленный LSTM (`Bidirectional=True`, 2 слоя, `hidden_size=256`).
   - Выходной вектор размерности 512 на каждый временной шаг.
3. **Классификатор и Функция потерь:**
   - Линейный слой `Linear(512, 37)` для 36 символов (`0-9`, `A-Z`) + 1 токен `blank` (индекс 0).
   - Функция потерь: `CTCLoss(blank=0, zero_infinity=True)`.
   - Оптимизатор: `Adam(lr=1e-4)`, `clip_grad_norm_=5.0`.

### 3.2. Трекинг автомобилей (`anpr_system/models/tracker.py`)
- Детекция транспорта классами COCO: легковые (`car`), мотоциклы (`motorcycle`), автобусы (`bus`), грузовики (`truck`).
- Алгоритм **ByteTrack** сохраняет постоянный уникальный ID автомобиля во время движения по кадру, что исключает повторный подсчет одной и той же машины при колебаниях детекции.

## 4. Контрастирование и Предобработка номеров

Перед подачей в нейросеть OCR кроп номера проходит пайплайн адаптивного контрастирования:
1. **Двусторонняя фильтрация (Bilateral Filter):** устраняет высокочастотный шум и артефакты сжатия видео, сохраняя границы символов четкими.
2. **CLAHE (Contrast Limited Adaptive Histogram Equalization):** локально выравнивает гистограмму яркости в условиях бликов, теней и ночной съемки (`clipLimit=3.0`, `tileGridSize=(8,8)`).
3. **Морфологическое выделение (Top-Hat / Black-Hat):** подчеркивает рельеф символов номера относительно фона пластины.
4. **Масштабирование:** приведение к $32 \times 128$ в оттенках серого с нормализацией `mean=[0.5], std=[0.5]`.

## 5. Метрики Обучения и Квантования (FP32 vs INT8)

Обучение проводилось на датасете казахстанских номеров `autoriaNumberplateOcrKz-2019-04-26` (8642 train, 1001 val, test).
После 12 эпох модель достигла **99.30% Accuracy** на валидации.

### Сравнение FP32 и INT8 FX Квантования:

| Метрика | FP32 (Базовая) | INT8 FX (Квантованная) | Результат |
| :--- | :--- | :--- | :--- |
| **Размер на диске** | 34.91 MB | **21.38 MB** | **-38.8% экономии** |
| **Время инференса (CPU)** | 69.73 мс / кадр | **11.62 мс / кадр** | **6.00x ускорение** |
| **Val Accuracy (Exact Match)** | 99.70% | 99.60% | Падение всего 0.10% |
| **Val CER (Char Error Rate)** | 0.0004 | 0.0005 | Практически идентично |
| **Test Accuracy (Unseen Data)**| 96.06% | 95.70% | Падение всего 0.36% |
| **Test CER** | 0.0064 | 0.0068 | Высочайшая устойчивость |

> **Вывод:** Квантование INT8 FX сокращает объем памяти и ускоряет инференс в **6 раз** практически без потери качества, что идеально укладывается в бюджет VRAM $\le 4$ GB.

## 6. Подсчет Автомобилей (True Count vs Estimate Count)

На тестовом видео `video.mp4` была задана контрольная линия (`pos_linha = 550`):
- **Собственный поток в прямом направлении (Forward / Down):** 23 автомобиля.
- **Встречный поток в противоположном направлении (Reverse / Up):** 19 автомобилей.
- **Итоговый подсчет системы (Estimate Count):** 42 уникальных авто.
- **Ручной эталон (True Count):** 45 авто.
- **Точность подсчета:** $93.3\%$.

Ошибки фильтрации были минимизированы благодаря трекингу центроидов и векторному контролю пересечения линии.

## 7. Интеграция с Telegram Bot

Демонстрационный бот (`anpr_system/tg_bot/bot.py`) поддерживает:
- `/compare_contrast` — наглядная генерация коллажа «До / После» контрастирования с распознанным номером.
- `/demo_ocr` — инференс CRNN на тестовых образцах.
- `/stats` — вывод сводки по потокам авто и точности.
- `/report` — отправка итогового markdown-отчета.
- **Прием фото:** пользователь может загрузить любое фото авто или номерного знака в чат и получить результат распознавания.

## 8. Инструкция по Установке и Запуску

### 8.1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 8.2. Обучение OCR
```bash
python anpr_system/pipeline/train_ocr.py --data-dir anpr_system/data/dataset_ocr --epochs 10
```

### 8.3. Обработка видео и подсчет автомобилей
```bash
python anpr_system/pipeline/video_processor.py
```

### 8.4. Запуск Telegram Bot
```bash
# Для интерактивного онлайн-режима:
export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН"
python anpr_system/tg_bot/bot.py

# Для автономного офлайн-тестирования:
python anpr_system/tg_bot/bot.py --offline
```
